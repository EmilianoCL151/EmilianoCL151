# 🧬 Proyecto principal

## 🔹 Predicción de resistencia antimicrobiana de *Mycobacterium tuberculosis*

Trabajo Terminal enfocado en el análisis de resistencia antimicrobiana de *M. tuberculosis* mediante técnicas de datos y machine learning sobre secuenciación genómica completa (WGS).

### Características

- Análisis exploratorio y estadístico
- Comparación y evaluación de **8 algoritmos de clasificación**
- Metodología de investigación + **CRISP-DM**, con desarrollo bajo modelo **Cascada**
- Herramienta web para gestión y análisis de información, desplegada en **AWS**
- Documentación científica y póster académico en **LaTeX/Overleaf**
- Uso de **R** y **Python**

> Proyecto académico en desarrollo. Por tratarse de información relacionada con salud, aquí solo se publica información general, sin datos clínicos identificables.

# 📌 Otros proyectos

## 🔹 Sistema de detección de inconsistencias vocacionales

Proyecto de machine learning para clasificar estudiantes según su trayectoria académica.

- Dataset del **UCI Machine Learning Repository**
- Reducción de **37 a 22 variables** con correlación de Pearson
- **SVM con kernel RBF**, evaluado con accuracy, F1 y validación cruzada K-Fold
- Resultados: **accuracy ≈ 0.935** y **F1 ponderado ≈ 0.933**

## 🔹 CodeLingo

Concepto de plataforma educativa gamificada para aprender programación con desafíos y seguimiento de progreso.

- **Spring Boot + Thymeleaf + MySQL**
- Login con roles, manejo de estados (acceso, error, logout)
- Rutas: `/home-alumno`, `/desafios`, `/progreso`, `/logros`, `/ranking`

## 🔹 Sistema de frenado inteligente

Controlador de frenado con **lógica difusa**, implementado en **Jupyter Notebook** con un componente de razonamiento en **Prolog**.

## 🔹 Arquitectura híbrida en la nube para encuestas

Diseño de una plataforma institucional de encuestas para hasta **10,000 usuarios concurrentes**, con nube híbrida y topología en **Cisco Packet Tracer**.

## 🔹 Prácticas y análisis de datos

- Spotify Top Songs 2010–2019 con **CRISP-DM**
- Clasificación de Iris con **KNN** y **Naive Bayes**
- Árboles de decisión y **Random Forest**
- Ejemplos didácticos de **CNN** y **RNN**
- Modelos de **Poisson**

## 🔹 Embebidos, hardware y redes

- **MSP430F5529**: timers, GPIO y UART (Code Composer Studio)
- **VHDL**, **RISC-V** y FPGA (Xilinx ISE / ISim)
- **ARP, DNS, DHCP, ICMP** con Wireshark y Packet Tracer
