# 🧬 Proyecto principal

## 🔹 Sistema para la predicción de resistencia antimicrobiana de *Mycobacterium tuberculosis*

Trabajo Terminal en el que desarrollo sistemas predictivos basados en **machine learning** para perfilar la resistencia antimicrobiana de *M. tuberculosis* a partir de **secuenciación genómica completa (WGS)**.

### Características

- Comparación de **8 algoritmos de clasificación**
- Metodología de investigación + **CRISP-DM**
- Desarrollo de software con modelo **Cascada**
- Plataforma web desplegada en **AWS**
- Documentación técnica en **LaTeX**

> Proyecto académico en desarrollo. Por el carácter de los datos clínicos, aquí solo se publica información general.
